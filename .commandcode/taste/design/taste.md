# Design Preferences

- Prefers real, recognizable brand logos with official brand colors for skills/technologies rather than generic, monochrome, or uniformly-tinted icons. Confidence: 0.85
- Prefers playful, interactive UI micro-interactions — e.g., skill items rendered as bubbles that repel/deviate when the cursor approaches. Confidence: 0.8
- Prefers larger, more visible UI elements (bigger circles/bubbles, larger icons and labels) over small or subtle sizing. Confidence: 0.7
- Prefers pronounced, clearly visible interactive effects (e.g., strong, obvious cursor-repel deviation) rather than subtle ones. Confidence: 0.7
- Prefers circular "bubble" presentation over rectangular boxes for skill/tech items. Confidence: 0.7
- Prefers solid black/dark body fills with a bold light border and subtle glow over translucent or lighter fills for UI elements. Confidence: 0.7
- Prefers interactive motion that is both responsive and smooth — elements react promptly and deviate with fluid spring-based easing (tight/high-stiffness settings) rather than jerky snapping or noticeable lag. Confidence: 0.8
- Prefers a minimal set of action links on project cards/modals — only Live Demo and GitHub — and omits extra links like Case Study. Confidence: 0.8
- Prefers modal/overlay content (e.g., project card details) to be natively scrollable, with global smooth-scroll libraries configured not to block wheel input inside them. Confidence: 0.7
- Prefers text-only presentation of projects, differentiated with colors and highlights (colored bands, tinted titles/accents), over emojis or images. Confidence: 0.85
- Prefers each project/card to have its own distinct accent color rather than colors shared across a category. Confidence: 0.8
- Prefers a dark purple base background palette for the site rather than neutral black/gray. Confidence: 0.8
- Prefers the particle theme to run as a full-page fixed background behind all content rather than being confined to the hero section. Confidence: 0.8
- Prefers symmetric, balanced layouts (e.g., equal-width counter/summary rows, evenly balanced grids) over asymmetric or lopsided arrangements. Confidence: 0.7
- Prefers key/featured items to be visually highlighted and emphasized (larger card, colored band/glow, accent color, "highlight" label) rather than presented at the same weight as surrounding items. Confidence: 0.7
- Prefers consistent design treatment across parallel/similar sections (applying the same featured-card + symmetric-grid pattern to every achievements block rather than styling each independently). Confidence: 0.65
- Prefers form/input UI to be visually rich and engaging (card container with a gradient accent band, radial glow accent, inline field icons, multi-column layout, animated gradient submit button) rather than plain, undecorated stacked inputs — describes bare forms as "dull". Confidence: 0.7
- Prefers real photos/images over emoji or character placeholders for personal/identity elements (e.g., replacing the About-section emoji with an actual profile photo). Confidence: 0.7
- Prefers text/badges overlaid on images (e.g., a college-name label on the About profile photo) to be clearly readable via a solid, high-contrast background with light text, rather than translucent or low-contrast treatment that can disappear against the image. Confidence: 0.6
